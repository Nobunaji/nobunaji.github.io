# Updating Root-Me Category Statistics

This project includes an automated way to fetch and display your Root-Me challenge completion statistics on the portfolio website.

## Setup

### 1. Get Your Root-Me API Credentials

You need valid API credentials from Root-Me:

1. Log in to [Root-Me](https://www.root-me.org)
2. Go to **Settings** → **API** (or navigate to: `https://www.root-me.org/en/Settings`)
3. Find your **User ID** and **API Key**
4. Copy both values

**Note:** The credentials in `.env` are examples and may not work. You must replace them with your actual credentials.

### 2. Update Environment Variables

Edit the `.env` file in the project root:

```env
ROOTME_USER_ID=your_actual_user_id_here
ROOTME_API_KEY=your_actual_api_key_here
```

Replace:
- `your_actual_user_id_here` with your numeric User ID from Root-Me settings
- `your_actual_api_key_here` with your complete API Key from Root-Me settings

## Updating Statistics

Run the update script to fetch your latest stats:

```bash
npm run update-stats
```

This will:
- Read credentials from `.env`
- Fetch all challenges from the Root-Me API
- Fetch your solved challenges
- Categorize and compute completion percentages
- Save results to `src/data/category-stats.json`

The statistics will be embedded in the page when you rebuild:

```bash
npm run build
```

## How It Works

1. **Build Time**: The Astro build process loads stats from `src/data/category-stats.json` and renders category badges in the challenge tree.

2. **Category Badges**: Each folder in the challenge tree displays a badge showing completion percentage (e.g., "75%") with a tooltip showing `solved/total` challenges.

3. **Data Flow**:
   - `update-category-stats.mjs` → Reads `.env` → Fetches from API → Writes to `src/data/category-stats.json`
   - Astro build → Reads from JSON file → Renders into HTML

## Rate Limiting

The Root-Me API has strict rate limits (1 req/60 seconds). The update script automatically:
- Waits between requests
- Respects `Retry-After` headers
- Retries on rate limit errors (HTTP 429)

If you hit the rate limit, wait 15 minutes before trying again.

## Troubleshooting

### "ROOTME_API_KEY and ROOTME_USER_ID environment variables are required"
- Verify your `.env` file exists and has these variables set
- Check that the values are not empty
- Make sure there are no typos in the variable names

### "got status 401 at offset 0" or "got status 401"
- Your API credentials are invalid or expired
- Get fresh credentials from https://www.root-me.org/en/Settings
- Update the `.env` file with the new values
- Try again

### "got status 429" (Rate Limit Exceeded)
- The Root-Me API rate limited your requests
- Wait 15 minutes for the rate limit to reset
- Try again later (the script will continue from where it left off)

### "The API may be unavailable"
- No challenges were fetched (possibly due to 401 error)
- Check your credentials are correct (see "got status 401" above)
- Verify the Root-Me API is online at https://api.www.root-me.org
- Check your internet connection

### "No category stats found" (when building)
- Run `npm run update-stats` first
- Ensure `src/data/category-stats.json` exists and is valid JSON
- Check the build output for any error messages

## Files

- `update-category-stats.mjs` - Standalone script to fetch stats from Root-Me API
- `src/data/category-stats.json` - Cached stats data (generated by the script)
- `src/pages/root-me.astro` - Loads stats at build time and renders badges
- `.env` - Environment variables (API credentials) - **Keep this private!**
